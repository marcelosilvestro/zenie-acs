# Catálogo de equipamentos homologados (oficial)

Um diretório por fabricante/modelo com `profile.json` (identificação, capacidades e fontes de dados, informações,
firmwares vistos) e, opcionalmente, `thumb.webp` (foto ≤ 200 KB). Carregado pelo zenie-api na subida e entregue em
cada release. Processo e formato: [docs/HOMOLOGACAO.md](../docs/HOMOLOGACAO.md).

Status de capacidade: `homologado` · `a-validar` · `nao-suportado`. Leitura é sempre exibida (menos `nao-suportado`);
**escrita só com `homologado`** (admin pode liberar caso a caso, auditado).
